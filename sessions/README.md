# Session Notes

This folder keeps dated notes so work can continue smoothly across sessions and devices.

Use this rule:

- `PROJECT_CONTEXT.md` stores stable long-term context.
- `SESSION_HANDOFF.md` stores the latest active state and next step.
- `sessions/YYYY-MM-DD-short-topic.md` stores historical notes for meaningful work sessions.

Before ending a meaningful session, update `SESSION_HANDOFF.md` and add or update a dated note here.

On a new device or new session, read `PROJECT_CONTEXT.md`, `SESSION_HANDOFF.md`, and the newest relevant session note before changing the app.
